В будущем может быть
====================

Идеи для развития TenderBauka (зафиксировано по разбору проекта).


ПРОДУКТ — высокий эффект
------------------------
• Уведомления (in-app) — СДЕЛАНО: колокольчик, офферы, заявки, сообщения, завершение сделки.
• Email / push-уведомления — чтобы не зависеть от открытой вкладки.
• Сравнение офферов — СДЕЛАНО: таблица цена / срок / доставка / рейтинг, метки лучшей цены и рейтинга.
• Отклонить / контрпредложение — СДЕЛАНО: reject (дорого / условия / другое) + counter с желаемой ценой.
• Рейтинг после сделки — СДЕЛАНО: оценка 1–5 после завершения, средний рейтинг на профиле и в офферах.
• Отмена заявки покупателем — СДЕЛАНО: отзыв статуса sent → cancelled.
• История закупок/продаж — СДЕЛАНО: отдельный раздел с фильтрами и поиском.
• Файлы — КП, фото товара, PDF (сейчас только текст).
• Напоминание о дедлайне оффера (5 часов) — СДЕЛАНО: in-app за ~1 час до сгорания.


МАТЧИНГ И КАТАЛОГ
-----------------
• Усилить матчинг для «хвостовых» категорий (сейчас лучше стройка и IT).
• Жёстче связать каталог с матчингом (товар → поставщик → заявка).
• Поиск и фильтры по городу, цене, сроку.
• Карточки товаров с фото и (опционально) ценой.
• Отдельный «Поиск» в сайдбаре (сейчас ведёт в чат) или переименовать пункт.


ДЛЯ ПОСТАВЩИКОВ
---------------
• Аналитика: число заявок, win-rate, среднее время ответа. — СДЕЛАНО
• Шаблоны ответов / быстрые офферы. — СДЕЛАНО
• Несколько категорий у одной компании. — СДЕЛАНО
• Статусы товара: в наличии / под заказ. — СДЕЛАНО


АДМИНКА И ДОВЕРИЕ
-----------------
• Модерация поставщиков и товаров.
• Проверка БИН / телефона.
• Жалобы и блокировки.
• Логи действий по сделкам.


ТЕХНИЧЕСКИЙ ФУНДАМЕНТ
---------------------
• PostgreSQL / SQLite вместо JSON (гонки при записи, нет бэкапов).
• Секрет сессии из env, debug=False в проде.
• CSRF / rate limit на API.
• Тесты полного пути: accept → messages → complete.
• README и нормальный деплой.


ПОЗЖЕ / МАСШТАБ
---------------
• Оплата / эскроу / счёт на оплату.
• Договоры и акты.
• Мультиязычность UI (KZ / RU / EN) — словари. — СДЕЛАНО
  Позже: MT API для чата/уведомлений (I18N_PROVIDER=api, /api/i18n/translate).
• LLM поверх chat_brain для сложных многопозиционных запросов.
• Мобильное приложение или PWA с пушами.


С ЧЕГО НАЧИНАТЬ ДАЛЬШЕ
----------------------
Продукт для пользователей: сравнение офферов → рейтинг → отмена/отклонение → email.
Стабильность и рост: БД + секреты → полный e2e → админка.
