# HupHup Admin

Отдельная панель администратора — не часть основного сайта (`huphup-frontend`),
отдельный проект и отдельный деплой, как `huphup-monitor`.

Вход только для аккаунтов с ролью `ADMIN`. Роль назначается напрямую в базе:

```sql
UPDATE users SET role = 'ADMIN' WHERE email = 'ваша@почта';
```

## Что внутри

| Раздел | Что делает | Backend |
|---|---|---|
| **Кошельки** | Личный баланс каждого пользователя: поиск, история, пополнение/списание | `/admin/wallets/*` |
| **Биллинг** | Кошельки компаний и покупателей, пополнение/корректировка | `/admin/billing/wallets`, `/topup`, `/adjust` |
| **Транзакции** | Вся денежная история площадки, фильтр по поводу списания | `/admin/billing/transactions` |
| **Цены** | Прайс-лист платформы и индивидуальные цены по компаниям | `/admin/billing/pricing` |
| **Сделки** | Все сейф-сделки, разбор спора через Gemini, выдача/возврат денег | `/admin/deals/*` |

«Кошельки» и «Биллинг» — два разных backend-модуля, которые исторически
выросли раздельно (см. `DOCS.md` бэкенда, раздел Billing). Панель не
притворяется, что это одно и то же — показывает оба честно, отдельными
разделами.

## Локальный запуск

```bash
npm install
cp .env.example .env
npm run dev -- --port 5175
```

Открыть: http://localhost:5175

Бэкенд должен быть запущен (см. `C:\dev\start-huphup.bat` в корне `C:\dev`).

## Деплой

Как `huphup-monitor` — отдельный проект на Vercel:

1. Отдельный репозиторий на GitHub (**обязательно приватный** — здесь
   работает вход администратора и управление деньгами).
2. Vercel → Add New Project → этот репозиторий.
3. Переменная окружения: `VITE_API_URL` = адрес боевого API
   (`https://huphup-api.onrender.com/api/v1`).
4. Никому не давать ссылку на этот деплой, кроме реальных администраторов —
   вход защищён паролем аккаунта, но сама страница входа доступна всем.
