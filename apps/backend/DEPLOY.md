# Cloud deploy (Neon + Render + Vercel)

```
Browser → Vercel (frontend / admin / monitor) → Render (NestJS API) → Neon (Postgres)
```

| Service | URL |
|---------|-----|
| **API** | https://huphup-api.onrender.com/api/v1 |
| **Health** | https://huphup-api.onrender.com/api/v1/health |
| **Swagger** | https://huphup-api.onrender.com/docs |
| **Frontend** | https://huphup-frontend.vercel.app |
| **Monitor** | https://huphup-monitor.vercel.app |

The API runs on Render's free plan: it sleeps after 15 minutes without traffic
and the first request after that takes about a minute.

## Neon (database)

1. https://console.neon.tech → project `huphup`, Postgres 16, region Frankfurt.
2. **Connect** gives two URLs, both with `?sslmode=require`:
   - pooling **on** (host contains `-pooler`) → `DATABASE_URL`
   - pooling **off** → `DIRECT_URL` (migrations can't run through the pooler;
     optional — derived from `DATABASE_URL` when left empty)

Migrations run automatically on every API start (`prisma migrate deploy`).
Free Neon storage is 0.5 GB and uploaded files are stored in Postgres unless
S3 is configured (`AWS_*` variables), so add S3/R2 before real traffic.

## Render (API)

Everything is described in [`render.yaml`](../../render.yaml) at the repo root.

1. https://dashboard.render.com → **New → Blueprint** → repo `Bauyrzhan01/huphup`.
2. Fill the prompted secrets: `DATABASE_URL`, `DIRECT_URL`, `MONITOR_SECRET`,
   `GEMINI_API_KEY` (optional). `JWT_SECRET` is generated by Render.
3. Deploys trigger on pushes to `main` that touch `apps/backend/**` or the
   workspace root files listed in `buildFilter`.

Build/start from the repo root, not `apps/backend`: pnpm needs the root
`pnpm-lock.yaml` and `pnpm-workspace.yaml`.

## Vercel (frontend, admin, monitor)

One Vercel project per app, all from repo `Bauyrzhan01/huphup`:

| Project | Root Directory | Environment variables |
|---------|----------------|-----------------------|
| `huphup-frontend` | `apps/frontend` | `VITE_API_URL=https://huphup-api.onrender.com/api/v1` |
| admin | `apps/admin` | `VITE_API_URL=https://huphup-api.onrender.com/api/v1` |
| `huphup-monitor` | `apps/monitor` | `VITE_API_HEALTH_URL`, `VITE_API_OPS_URL`, `VITE_FRONTEND_URL`, `OPS_URL`, `MONITOR_SECRET` (same value as on Render) |

`VITE_*` values are baked in at build time — redeploy after changing them.
Each app's `vercel.json` pins pnpm via `installCommand` (Vercel only auto-detects pnpm up to 10);
frontend and admin also rewrite SPA routes to `/index.html`.

## CORS

The API accepts origins listed in `CORS_ORIGINS` plus any `*.vercel.app`,
`localhost` and `127.0.0.1`. A custom frontend domain must be added to
`CORS_ORIGINS` on Render.
