# Сценарий S5: прямой запрос по товару

Заказчик открывает карточку конкретного товара поставщика в каталоге и шлёт
запрос **адресно** (`POST /requests/direct`) — не публичную заявку по всему рынку.
Лид уходит только этому поставщику, со `score 100` и активностью
«Direct product request».

## Запуск

```bash
# нужен бэкенд :3000, фронт :5173 и товары «Профнастил С8» у поставщиков
# (их создаёт любой предыдущий сценарий; иначе run.mjs создаст сам)
cd apps/backend/scripts/scenario-direct-product
node run.mjs          # → state.json
node screenshot.mjs   # 3 скрина в screenshots/
```

## Проверяется

- товар виден в публичном каталоге (`GET /products/catalog`);
- целевой поставщик получил лид, `score = 100`, лид привязан к товару;
- **другой** поставщик того же товара лид **не** получил (адресность);
- у заявки ровно 1 лид.

## Скрины

| файл | кто | что |
|---|---|---|
| `01` | заказчик | карточка товара + форма «Заявка на этот товар» (уйдёт только этому поставщику) |
| `02` | заказчик | заявка адресована 1 поставщику |
| `03` | целевой поставщик | «Входящие» — прямой лид, `score 100`, «Direct product request» |

## Заметка

`GET /products/catalog?q=<текст>` раньше отдавал `400` (глобальный `ValidationPipe`
не пускал `q` мимо `PaginationQueryDto`) — починено: добавлен
`ProductCatalogQueryDto`. Скрипт снова ищет товар обычным запросом `?q=Профнастил`.
